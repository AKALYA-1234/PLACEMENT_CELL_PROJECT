# Sample Data Directory

Store sample company placement Excel files (`.xlsx`, `.xls`) in this directory for testing the Excel parser and normalization pipeline in Phase 2.

Expected sheet variations to test:
- Single-sheet workbooks with round columns
- Multi-sheet workbooks (Round 1, Round 2, Shortlisted, Selected/Offered)
- Varying column titles for Register Number (e.g. `Reg No`, `Register Number`, `Roll No`, `Reg_No`, `HTNO`)
